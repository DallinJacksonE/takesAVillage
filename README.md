# Takes a Village

Takes a Village is a social dilemma game about specialization, societies, and survival. 


You will need a config file in the service dir:
```{
  "db": {
    "user": "root",
    "password": "your_real_password",
    "host": "127.0.0.1",
    "database": "village_db"
  },
  "flask": {
    "secret_key": "complex_random_string_here"
  }
}```
